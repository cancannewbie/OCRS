# 前端回归

运行环境：Node.js 22 或更新版本。依赖只用于开发测试，不进入 FastAPI 运行时。

```sh
npm ci
npm run test:frontend
```

`node:test` 直接加载实际 `src/ocrs/static/index.html` 与 `app.js`，每个用例独立创建
jsdom、虚构任务、受控 API 替身和内存会话。测试不会读取真实数据、启动外部模型或产生费用。
`jsdom` 是提供原生 DOM 的唯一模拟依赖；无需额外前端框架或打包工具。
`package-lock.json` 由 npm 实际安装生成，CI 使用 `npm ci` 保持解析一致。

覆盖范围：

- 令牌校验、仅当前会话保存、退出/401 清理、未提交草稿保护
- 不可信文本与源 URL、认证图片和导出 blob、禁止带令牌跟随重定向
- 延迟 fetch 和延迟 response body、跨任务图片、跨登录会话的陈旧响应
- 上传表单关闭重开、提交期间锁定、未知结果和同来源去重重试
- 审核校验、二次确认、重复风险显式确认、幂等键复用与单次在途操作
- 草稿与输入焦点保留、版本冲突、重新载入、重识别、驳回
- 导航、分页/搜索/筛选、原图缩放、只读配置诊断、导出状态
- 五类弹窗的显式 Tab / Shift+Tab 首尾循环、隐藏/禁用控件排除、全禁用时焦点回退
- 编辑控件、中文输入法组合、已处理事件和浏览器组合键不触发全局导航快捷键
- 提交、导入、复审、模型配置和导出有文字及 `aria-busy` 反馈；失败、退出和跨会话陈旧响应恢复状态
- 按钮恢复保留 SVG，动态图标不改变可访问文字；断连或禁用弹窗触发器关闭后有可见焦点后备
- 队列勾选的标签点击维持原选择范围，订单横向滚动区域可通过键盘聚焦

所有时钟均可控；等待只用于清空已排队的异步回调，不等待真实网络或轮询间隔。
jsdom 的 dialog 和 blob 下载使用最小替身，因此这些测试不证明视觉布局、真实浏览器
原生 Tab 遍历、图片解码、下载字节或 CSS 可访问性。焦点边界用例主动设置焦点并模拟
可见控件的布局矩形，不替代 Chromium 的键盘验收。真实浏览器流程另见 `tests/e2e/`，
运行 `npm run test:e2e`，不要把仅 DOM 通过写成视觉验收通过。

## 图片识别主路径回归

upload-navigation.test.cjs 增加来源无关的结果页与 API 接入断言：正式多图逐张提交、单图 multipart、本批外传授权、部分成功后逐图幂等键复用；原始模型值与人工修正独立，未知 SKU、null、十进制文本、原文证据可直接读取。未完成和失败状态不回退 demo，可选订单接口失败也不阻塞结果读取。

结果原图经鉴权读取为受保护 blob，不信任来源 URL；覆盖失效/陈旧图片、原图手动重试、退出时结果与 blob 清理、旧会话响应隔离。自动轮询不得覆盖显式选择的焦点，也不重建未变化的展开 JSON。API 契约仅以占位凭据展示，通过鉴权本机请求读取 OpenAPI，不创建真实凭据。
