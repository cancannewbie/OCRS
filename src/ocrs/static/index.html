API INTEGRATION

API 接入

来源系统负责获得图片。本服务接收图片文件，异步提取并返回未经人工核实的结构化结果。

接入与授权

默认仅监听本机 127.0.0.1。请求携带现有本地访问令牌，模型 API 密钥留在后端。下列令牌与图片路径均为占位符；页面不会创建凭据。

先读取 GET /api/model-settings，核对 provider、base_url、model、revision 和 allow_external。必须先配置真实图片模型；正式入口在 demo 下返回 MODEL_NOT_CONFIGURED，不会假识别。保存配置不联网。

调用方须明确授权当前目的地、本次完整图片与识别用途，并接受供应商费用。外部开关关闭时，在授权后调用 POST /api/model-settings/enable-external，JSON 为 {"expected_revision": 1, "confirm_external": true}，再使用返回的新 revision。每次上传仍须发送 config_revision 与 confirm_external=true。禁用或更换模型后，旧任务不会暗中外传。

不接收外部图片 URL，不访问图片中的链接或执行其指令。source_label 只是可选备注，不是身份凭据。

1. 上传一张虚构图片

单图 multipart：file、可选 source_label、可选 idempotency_key（8–100 字符）、当前 config_revision 与本图授权。返回 HTTP 202 和 task_id。

curl -X POST "http://127.0.0.1:8000/api/recognitions" \
  -H "Authorization: Bearer <LOCAL_ACCESS_TOKEN>" \
  -F "file=@synthetic.png;type=image/png" \
  -F "source_label=synthetic-example" \
  -F "idempotency_key=synthetic-request-001" \
  -F "config_revision=<CURRENT_REVISION>" \
  -F "confirm_external=true"

仅支持实际可解码的静态 PNG、JPEG、WebP。单次一张、默认最大 10 MiB、最多 2 千万像素，声明类型必须与实际内容一致。当前限制以 GET /api/config 为准。多图分别提交，不保证整个批次原子成功。

同幂等键同有效载荷或同图同来源备注复用任务，不重复识别；同键不同载荷返回 IDEMPOTENCY_CONFLICT。更换备注可明确创建独立图片任务，不自动合并业务订单。

2. 轮询状态并读取结果

curl "http://127.0.0.1:8000/api/recognitions/<TASK_ID>" \
  -H "Authorization: Bearer <LOCAL_ACCESS_TOKEN>"
curl "http://127.0.0.1:8000/api/recognitions/<TASK_ID>/result" \
  -H "Authorization: Bearer <LOCAL_ACCESS_TOKEN>"

received → recognizing → succeeded，失败为 failed。建议每 2 秒轮询，设置调用方总超时。成功结果包含 schema_version、task_id、status、verified:false、recognition_mode、独立 review_status 与原始 result；result 包含 events、evidence、warnings 与 missing_reasons。数量与金额为十进制字符串；未知值保持 null。

import os
import time
import requests

base = "http://127.0.0.1:8000"
headers = {"Authorization": "Bearer " + os.environ["OCRS_LOCAL_TOKEN"]}
# 先核对目的地并获得本图授权；填写启用后的当前版本。
revision = "<CURRENT_REVISION>"
with open("synthetic.png", "rb") as image:
    response = requests.post(base + "/api/recognitions",
        headers=headers, files={"file": ("synthetic.png", image, "image/png")},
        data={"source_label": "synthetic-example",
              "idempotency_key": "synthetic-request-001",
              "config_revision": revision, "confirm_external": "true"},
        timeout=30)
response.raise_for_status()
task_id = response.json()["task_id"]
for _ in range(60):
    status = requests.get(base + "/api/recognitions/" + task_id,
                          headers=headers, timeout=15)
    status.raise_for_status()
    task = status.json()
    if task["status"] == "failed":
        raise RuntimeError(task["error_code"])
    if task["status"] == "succeeded":
        result = requests.get(base + "/api/recognitions/" + task_id + "/result",
                              headers=headers, timeout=15)
        result.raise_for_status()
        print(result.json())  # 仅虚构示例；生产结果避免写日志
        break
    time.sleep(2)
else:
    raise TimeoutError("本次等待结束；保留 task_id，稍后查询")

错误与兼容边界

HTTP / 错误码处理方式
401 UNAUTHORIZED核对本地访问令牌；不在 URL 或日志中传递。
400 IMAGE_INVALID / IMAGE_TYPE_MISMATCH上传实际有效、类型匹配的静态图片。
413 IMAGE_TOO_LARGE缩小文件或图片像素。
409 MODEL_NOT_CONFIGURED / MODEL_DISABLED配置真实模型；核对明确外传授权和开关。
409 MODEL_CONSENT_REQUIRED / MODEL_CONFIG_CHANGED重新核对目的地、当前版本与本图范围，明确授权后提交或重试。
409 RESULT_NOT_READY / RECOGNITION_FAILED未完成时继续查询；失败时检查安全 error_code，不自动切换 demo。
409 DEMO_SOURCE_CONFLICT旧 demo 同图同来源已存在；更换来源备注再真实识别，保留演示数据。
409 IDEMPOTENCY_CONFLICT同键只能重放原请求；新图片使用新键。
429 QUEUE_FULL队列容量已满，稍后按同键重试。单进程、一个识别 worker。
410 EVIDENCE_EXPIRED原图已清理，识别证据无法恢复。

完整字段与实时限制可通过鉴权的 GET /api/openapi.json 和 GET /api/config 查询。旧 /api/uploads 与 /api/tasks 保留兼容及显式离线演示；审核、订单与 Excel 为可选下游。文件夹导入已停用，不再启动来源扫描；已有数据保留。
