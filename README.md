# OCRS
Order Collection and Review System

面向微信客户下单截图的订单采集、识别、审核与表格导出项目。

## 开发规范

- [项目代码规范](docs/CODING_STANDARDS.md)：架构边界、数据模型、识别审核、安全、测试和验收
- [贡献指南](CONTRIBUTING.md)：分支、提交、评审和验证要求
- [代码代理工作约定](AGENTS.md)：供 AI 编程代理及开发者执行的简明规则

当前仓库仅包含规范和基础编辑配置，尚未实现采集器、后端、审核界面或表格导出，也未配置依赖、测试和 CI。规范中的目录与工具是后续实施建议，不代表已存在。

开始实现前需确认：微信接入方式及授权、运行平台、导出目的地、订单字段、处理规模与数据保留期限。技术选型在首次实现时通过简短设计记录确认。
