# ADR 0004：页面模型设置、密钥隔离与外传授权

- 版本：0.2.3
- 日期：2026-10-10
- 范围：单人、单机、本地模型配置；不改变人工审核与正式订单边界

## 背景

模型环境变量要求操作者编辑文件并重启，难以区分“已保存”“已授权”和“已测试”。直接套用旧环境还可能让历史队列被新供应商处理。用户需要通过页面配置模型，而不是模型配置文件。

## 决策

1. 鉴权页面/API 是模型配置的唯一运行时入口，配置具有单调版本和乐观并发校验。全部旧模型环境变量忽略，不自动导入或覆盖；数据路径、访问令牌、inbox 与 SKU 仍属基础运维设置。
2. 保存只校验并持久化，不解析 DNS 或调用模型，无需重启。默认 demo、外部调用关闭。OpenAI 兼容模型要求图片与严格 schema；MiniMax 中国适配器锁定官方中国地址及 MiniMax-M3，以完整 schema 提示加本地严格验证保持其既有契约。
3. 密钥采用只写 API，状态读取只返回是否配置。空白配合 keep 保留，replace/delete 显式处理；供应商或目的地变化不能复用旧密钥。前端不持久化秘密，日志与错误不回显。
4. 单独 `model-settings.sqlite3` 保存非秘密元数据与 AES-256-GCM 密文。主密钥在数据目录外 `~/.ocrs-model-keys`，按规范化根路径哈希区分，AAD 绑定该身份。POSIX 使用受限目录/文件权限；Windows 用当前账户 DPAPI 保护主密钥，无明文降级。
5. 内置业务备份排除模型存储和主密钥。恢复新数据目录后重新配置，不能把搬运密文当作可用恢复。防护目标是意外泄露数据库或业务备份，不涵盖同账户、管理员、恶意程序与进程内存；任意第三方备份不继承内置排除保证。
6. 显式测试经确认只发送系统生成虚构 PNG、指令与 schema，可能计费；绝不选取现有业务截图。成功状态不等于生产准确率、账户全部能力或供应商数据政策验收。
7. 业务 schema 2 为任务增加配置版本和外传授权。上传/重试需当前目的地及图片范围确认；配置变化使旧待处理任务暂停，inbox 不自动授权真实外传。已经开始的请求可按不可变原快照完成，不承诺切换配置立即撤销在途请求。
8. 请求仅限公网 HTTPS 443，无 URL 凭据/查询/片段；校验全部 DNS 地址并固定实际 TCP 连接，TLS/SNI 仍校验原主机名，禁用重定向与环境代理。不支持本地/私网模型代理。

## 依赖与取舍

新增 `cryptography`，使用维护中的标准 AES-GCM 实现而不自制密码算法；直接声明 `httpcore`，以受控网络后端固定经过验证的地址，同时保留原始 HTTP/TLS origin。依赖及锁定版本由包管理器生成并接受离线回归验证。

这是本机威胁模型，不是操作系统密钥保险箱或多人权限系统。Windows DPAPI 绑定账户；POSIX 依靠文件权限隔离主密钥。服务仍能在识别期间接触明文凭据，单一访问令牌持有人可编辑设置和授权调用。

## 升级与验证

停止旧服务并完成业务备份，安装锁定依赖，运行 `ocrs init` 显式迁移 schema 1 → 2，登录后重新填写模型设置。操作者自行清除旧环境秘密；不自动读取或删除其文件。不提供自动降级。

测试全部用虚构数据和离线替身，覆盖加密/密钥动作、鉴权与并发、旧环境忽略、保存零网络、副作用边界、测试合成输入、目的地授权、旧队列与 in-flight 快照、备份恢复、SSRF/DNS/TLS 与前端交互。实际最终结果见对应提交 CI；测试存在不等于验收通过，未调用真实供应商也不能证明真实 OCR 质量。

操作步骤与预算限制见 [OPERATIONS](../OPERATIONS.md)，验收入口见 [ACCEPTANCE](../ACCEPTANCE.md)。
