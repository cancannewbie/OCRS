# 0006：来源无关的截图识别服务

- 日期：2026-10-10
- 状态：采用，适用 0.3.0
- 范围：获授权图片接收 → 异步模型提取 → 未经人工核实的结构化结果
- 替代：[0001](0001-local-workflow.md) 的主流程与目录导入边界；保留其订单、金额、证据、事务与安全约束

## 背景与目标

系统只负责识别截图信息。数据来源由调用方负责，通过正式 API 接入，或由操作者在页面手动上传。获取结构化结果不能以完成审核、商品目录映射或 Excel 导出为前提。

本次不开发、调用或接入微信组件，不抓取聊天，不监听桌面，不扫描收件目录。单人、单机、回环监听与现有 Bearer 令牌边界不变；没有公网服务、多用户权限、回调或 webhook。

## 接收与任务契约

复用已有图片校验、受控证据存储、任务、模型适配器与候选契约，新增正式识别边界而不另建订单事实源。

`POST /api/recognitions` 接收一张 multipart 图片、可选来源备注与外部幂等键，返回 202、任务 ID、状态、版本与结果地址。调用方通过鉴权状态/结果接口轮询。PNG/JPEG/WebP 必须通过声明 MIME/真实内容一致校验和完整解码，每图最多 10 MiB、2,000 万像素；拒绝动画、损坏图、URL 与额外文件。

来源备注是调用方提供的不可信上下文，不是账号身份、提取规则或执行指令。技术去重按图片字节摘要与来源标签；重复提交复用任务，不自动重识别、重新授权或恢复已过期证据。旧 demo 同图同来源不得成为正式提取结果，返回 `DEMO_SOURCE_CONFLICT`；已过期来源返回 `EVIDENCE_EXPIRED`。外部幂等键绑定图片摘要、来源标签、配置版本与图片外传确认，同键异内容报冲突，映射持久保存在数据库中。单 worker 顺序识别，待处理容量为 100，容量拒绝后调用方退避重试同一请求。

具体字段、状态、重复行为、错误与可运行调用示例以 [识别 API](../RECOGNITION_API.md) 为准，鉴权 `/api/openapi.json` 与实现保持一致。

## 结果与可选下游

结果是模型产生且经本地 schema 校验的原候选，保留证据、缺失值、警告和精确十进制字段。图片里的指令仅作为数据，不能修改固定提取规则、授权外传、打开链接或获得工具执行权限。

提取成功后即可读取结果。未知商品编码或尚未审核不阻塞结果；人工修改与确认值单独保留，不覆盖原模型候选。结果不等于正式订单入账，也不能直接进入原正式订单 Excel 导出。

原审核、驳回复审、新单/改单/撤单、订单历史、outbox 与 XLSX 保留为可选下游。它们继续要求完整字段、商品目录规则、版本、操作者、原因、幂等与人工确认，不因新 API 入口减弱要求。

## 外传与错误边界

正式识别 API 要求真实模型配置；默认 demo 返回 `MODEL_NOT_CONFIGURED`，绝不回退为假识别。旧上传接口仅保留兼容及显式离线演示。

每次新提交或失败重试须核对当前模型配置版本、具体目的地、当前图片范围与费用，并显式确认外传；API 的 Bearer 鉴权和来源备注不能替代这份授权。模型配置保存不联网。配置更换、密钥删除或关闭外部调用后，旧待处理任务不能暗中发送；已开始请求按原不可变快照完成，不能承诺即时撤回已发送数据。

结果未就绪和识别失败分别返回可处理的稳定错误码。错误、日志与诊断不回显图片/OCR 原文、供应商原始响应、秘密、路径或请求头。原图与结果仅由鉴权接口提供，调用方仍须保护其下载、副本和保留期限。

## 兼容、迁移与恢复

业务 schema 3 → 4 新增识别请求的持久幂等映射；不删除或重解释旧来源、任务、候选、人工修订、订单、事件、导出或模型设置。旧任务查询、上传、审核和导出接口保留。`OCRS_INBOX` 被忽略，运行时不创建目录扫描器；旧类库保留仅为兼容历史代码与测试，不作为接入方案。

升级前停机备份，在隔离新目录演练 `ocrs init` 和恢复；旧程序不支持 schema 4，不直接打开已升级数据库。回退使用升级前备份恢复到新目录。业务备份仍不包含模型设置与主密钥，恢复后重新配置并逐个核对任务授权。完整步骤见 [运维说明](../OPERATIONS.md)。

## 验收

使用完全虚构图片、临时数据库与模型 mock；不读用户密钥、令牌或真实订单，不调用付费模型，不上传真实图片，不重启用户服务。验收覆盖鉴权、图片边界、耐久幂等、容量、并发、结果未就绪/失败、配置变化及旧审核/复审/导出回归，另验桌面/窄屏与键盘流程。具体通过状态只按最终提交的实际检查与 CI 记录报告，文档或测试文件存在不代表验证通过。
